# assets

本目录存放对外发布的品牌资产。

| 文件 | 用途 |
|---|---|
| `logo.svg` | 插件标识（矢量，可缩放） |
| `logo-readme.svg` | README 顶部横幅（预留，未使用） |

## 约束

- **只用矢量**：位图在深色/浅色主题下无法自动适配，会出现"白底白字"。
- **不写死颜色**：`logo.svg` 用 `currentColor` 与半透明填充，跟随宿主主题。
- 尺寸基准 64×64，`viewBox` 不要改 —— 改了两处引用（README / 面板）会不同步。

## 命名

`logo.svg` 是**对外契约名**（README 与 npm 页面都指向它），改名等于断链。
